This project is the base architecture for this blog.

It focuses on three goals:

1. Keep publishing friction low.
2. Keep visual identity consistent.
3. Keep content structure obvious for future edits.

The content model now supports articles, projects with multiple notes, and a reading
list with optional per-item notes.
